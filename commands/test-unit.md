# /test-unit Command

Creates fast, isolated unit tests for business logic.

---

## 1. Identity & Execution

- **Lead Agent:** Merry
- **Specialist Agent:** qa-specialist
- **Category:** Testing

---

## 2. Trigger Syntax

```bash
/test-unit <source-file>
```

---

## 3. Workflow Protocol

1. **Step 1:** Extract pure functions and edge cases from target file.
2. **Step 2:** Scaffold unit tests with mock boundaries.
3. **Step 3:** Verify tests run with zero network or disk dependencies.

---

## 4. Hard Verification Gates

- Test execution must complete within milliseconds.
