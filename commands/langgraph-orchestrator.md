# /langgraph-orchestrator Command

Designs stateful agent graphs with checkpoints and approval interrupts.

---

## 1. Identity & Execution

- **Lead Agent:** Gandalf
- **Specialist Agent:** graph-designer
- **Category:** Planning

---

## 2. Trigger Syntax

```bash
/langgraph-orchestrator <workflow>
```

---

## 3. Workflow Protocol

1. **Step 1:** Declare typed state schema with approval flags for side effects.
2. **Step 2:** Lay out nodes and conditional edges with checkpoint persistence.
3. **Step 3:** Present the graph blueprint for approval before coding.

---

## 4. Hard Verification Gates

- Guard every side effect with an interrupt.
- Verify human approval before implementation.
