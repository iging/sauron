# /prd Command

Converts feature concepts into structured PRD specifications.

---

## 1. Identity & Execution

- **Lead Agent:** Gandalf
- **Specialist Agent:** planner
- **Category:** Planning

---

## 2. Trigger Syntax

```bash
/prd <product-feature>
```

---

## 3. Workflow Protocol

1. **Step 1:** Interrogate user for problem statement and target audience.
2. **Step 2:** Define user stories with verifiable acceptance criteria.
3. **Step 3:** Document scope boundaries in context/PRD.md.

---

## 4. Hard Verification Gates

- Every user story must have measurable validation criteria.
