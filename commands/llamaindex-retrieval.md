# /llamaindex-retrieval Command

Wires enterprise sources into domain query engines with refresh policy.

## 1. Identity & Execution

- **Specialist Agent:** data-connector
- **Category:** Execution

---

## 2. Trigger Syntax

```bash
/llamaindex-retrieval <sources>
```

---

## 3. Workflow Protocol

1. **Step 1:** Inventory sources with access rules and freshness needs.
2. **Step 2:** Define one index per domain with permission filters and routing table.
3. **Step 3:** Present the wiring plan with refresh policy for approval.
