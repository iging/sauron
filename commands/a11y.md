# /a11y Command

Audits interfaces for WCAG 2.1 AA accessibility compliance.

---

## 1. Identity & Execution

- **Lead Agent:** Legolas
- **Specialist Agent:** a11y-auditor
- **Category:** Review

---

## 2. Trigger Syntax

```bash
/a11y <component-path>
```

---

## 3. Workflow Protocol

1. **Step 1:** Verify semantic HTML element usage.
2. **Step 2:** Confirm visible keyboard focus on interactive elements.
3. **Step 3:** Check contrast ratios and ARIA attributes.

---

## 4. Hard Verification Gates

- Prohibit non-semantic interactive divs without role.
