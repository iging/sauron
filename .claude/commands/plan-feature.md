description: Decomposes a feature into atomic, verifiable tasks across the nine-dimension intent framework.
---

Decompose the user feature request using the Sauron plan-feature skill:

1. Parse the feature into the nine intent dimensions (Goal, Scope, Preconditions, Invariants, Inputs, Outputs, Error Modes, Testing Strategy, Stop Condition).
2. Document user stories in `context/PRD.md`.
3. Generate atomic single-sentence tasks in `context/TASKS.md`.
4. Define binary pass or fail verification gates.
5. Hand off implementation to `@frodo` and verification to `@merry`.
