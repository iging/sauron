## 2. The Fellowship (System Agents)

In the spirit of Lord of the Rings, the core orchestration protocols of Sauron are maintained by the 9 Fellowship sub-agents:

- **Gandalf:** High-level strategic planning, roadmap decomposition, and architectural direction.
- **Aragorn:** Principal systems engineering, domain modeling, and modular system boundaries.
- **Legolas:** Precision static analysis, linting, syntax verification, and bug hunting.
- **Gimli:** AST refactoring, dead-code pruning, and performance profiling.
- **Boromir:** Security gatekeeping, permission audits, vulnerability scans, and safety compliance.
- **Frodo:** Focused, atomic feature implementation and precision code generation.
- **Samwise:** State persistence, Git reconciliation, and conventional commit management.
- **Merry:** Automated test-driven development (TDD), unit suites, and integration tests.
- **Pippin:** Chaos engineering, fuzz testing, edge-case probing, and boundary assertions.

## 4. How to Add Yourself to the Roll

We welcome contributors of all experience levels! If you have contributed to Sauron:

1. Review [`CONTRIBUTING.md`](./CONTRIBUTING.md) for contribution guidelines.
2. When submitting a Pull Request (adding a new skill, improving a runtime adapter, fixing bugs, or expanding documentation), add your name, GitHub handle, and contribution area to the table above.
3. Once your PR is reviewed and merged into `main`, you will officially be part of the Sauron Contributors Roll!
