# Use This Vault in Obsidian

Open docs/sauron-second-brain as the vault folder. Start with [[claude]].

- [[resume-brief]] starts an agent session. [[task-file-map]] routes one task.
- [[history-index]] provides historical evidence on demand.
- Unique note names support wiki links, graph, and backlinks.
- No community plugin, cloud sync, or paid service is required.
- Per-user layout stays in ignored .obsidian/. Preserve it during cleanup.
- Original handoffs stay outside this vault, at docs/handoffs/.
  Use [[handoffs-index]] and open exact sources in the repository editor.
- Default Welcome content is retired. [[claude]] is the durable starting note.

## Portability limits

Root AGENTS.md, CLAUDE.md, and GEMINI.md point here. Discovery depends on the runtime.
If it misses the entry note, paste the prompt in [[resume-brief]] and confirm it is loaded.
The vault cannot guarantee another runtime's automatic memory loading.

Sauron Obsidian UI verification remains pending. Disk checks do not prove the app layout.
