# Terracotta Craft

Warm cream, fired-clay accent, dark warm ink. Built things and honest materials.

- **Fits:** Trades, builders, potters, cafes, makers, local services.
- **Avoid for:** Fintech, developer tools, clinical brands.

## Tokens

```yaml
color:
  canvas: "#FAF6EF"
  surface: "#F2EADC"
  ink: "#201A16"
  ink-muted: "#6B5F55"
  hairline: "#E2D6C4"
  accent: "#A4482B"
  on-accent: "#FFF8F0"
type:
  display: "Slab serif, semibold"
  body: "Humanist sans, regular"
  mono: "Not used"
  scale-ratio: 1.25
  display-weight: 600
  display-tracking: "-0.015em"
shape:
  radius-control: "4px"
  radius-card: "8px"
  radius-container: "12px"
space:
  base: 4px
  section: "96px"
motion: "240ms ease-out, one entrance per section"
```

The type entries name a character, not a licensed family. Map each to a face the project can load, then record the choice in the project `DESIGN.md`.

## Depth

Surface tint and a coloured top edge on cards. No shadows.

## Signature Moves

- A drawn motif from the trade as the hero image.
- A dark band between cream sections.
- Cards laid in a running-bond grid.

## Never

- Cool greys.
- Stock handshake photos.
- Gradient buttons.

## Contrast Evidence

| Pair                 | Ratio     | Required |
| -------------------- | --------- | -------- |
| Ink on canvas        | 16.0 to 1 | 7 to 1   |
| Ink on surface       | 14.4 to 1 | 7 to 1   |
| Muted ink on canvas  | 5.7 to 1  | 4.5 to 1 |
| Muted ink on surface | 5.2 to 1  | 4.5 to 1 |
| On-accent on accent  | 5.6 to 1  | 4.5 to 1 |
| Accent on canvas     | 5.5 to 1  | 3 to 1   |

Semantic colours (success, warning, danger) are not part of a pack. Take them from the project token set and check them against this canvas.
