# Style Token Packs

Fifteen ready-to-apply starting points. Each pack is a small token set plus the three moves that define the style and the three that break it. `../../ui-design/tokens/styles.md` remains the broad catalogue of 84 styles; a pack exists only where a style is used often enough to deserve fixed values.

Packs are platform-neutral: hex colours, type characters, and unitless sizes. To turn one into CSS, SwiftUI, Compose, Flutter, or XAML, follow `../../foundations/platform-code-examples.md`.

## How to use

1. Pick one pack from the Design Read. Do not blend two.
2. Copy its tokens into the semantic tier of the project token set (`skills/quality/design-tokens/SKILL.md` defines the tiers).
3. Map each type character to a real, loadable family.
4. Keep the Signature Moves; treat the Never list as hard bans.
5. For a specific company look, use a brand preset in `skills/frontend/brand-presets/` instead.
