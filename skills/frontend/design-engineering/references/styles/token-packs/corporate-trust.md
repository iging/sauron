# Corporate Trust

Clean, navy-led, predictable. Credibility over novelty.

- **Fits:** Insurance, banking, B2B services, public bodies, healthcare providers.
- **Avoid for:** Creative portfolios, youth brands.

## Tokens

```yaml

  canvas: "#F8FAFC"
  surface: "#FFFFFF"
  ink: "#0F172A"
  ink-muted: "#52607A"
  hairline: "#E2E8F0"
  accent: "#1E40AF"
  on-accent: "#FFFFFF"
type:
  display: "Neutral sans, semibold"
  body: "Neutral sans, regular"
  mono: "Not used"
  scale-ratio: 1.2
  display-weight: 600
  display-tracking: "-0.015em"
shape:
  radius-control: "4px"
  radius-card: "8px"
  radius-container: "12px"
space:
  base: 4px
  section: "80px"
motion: "150ms ease-out, state changes only"
```

The type entries name a character, not a licensed family. Map each to a face the project can load, then record the choice in the project `DESIGN.md`.

## Depth

Hairline borders with one soft shadow level on cards.

## Signature Moves

- Credentials and accreditations shown near the first action.
- Plain-language headings.
- Step indicators on every multi-step form.

## Never

- Violet gradients.
- Playful illustration.
- Hidden contact details.

## Contrast Evidence

| Pair                 | Ratio     | Required |
| -------------------- | --------- | -------- |
| Ink on canvas        | 17.1 to 1 | 7 to 1   |
| Ink on surface       | 17.9 to 1 | 7 to 1   |
| Muted ink on canvas  | 6.1 to 1  | 4.5 to 1 |
| Muted ink on surface | 6.3 to 1  | 4.5 to 1 |
| On-accent on accent  | 8.7 to 1  | 4.5 to 1 |
| Accent on canvas     | 8.3 to 1  | 3 to 1   |

Semantic colours (success, warning, danger) are not part of a pack. Take them from the project token set and check them against this canvas.
