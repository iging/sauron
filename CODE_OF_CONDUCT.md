# Code of Conduct

Sauron is a project for anyone who wants better AI coding tools. Everyone who takes part should feel welcome and safe.

## Expected behavior

- Be respectful, including when you disagree.
- Give feedback on the work, not the person.
- Assume good intent, and ask before you assume.
- Help newcomers.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Discrimination or hateful language.
- Sharing private information about someone without permission.
- Spam, or repeated disruption of discussions.

## Where this applies

These rules apply in project spaces, including issues, pull requests, and reviews.

## Reporting

Report a problem privately through a [GitHub private advisory](https://github.com/iging/sauron/security/advisories/new). Maintainers will review each report and may edit or remove content, or block an account from the project.
