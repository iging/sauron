# Support

## Get help

1. Read the [docs](./docs/README.md), starting with the [FAQ](./docs/01-getting-started/faq.md).
2. Run `npx sauron-ai status` to see your runtimes, agents, and skills.
3. Search the [existing issues](https://github.com/iging/sauron/issues).
4. Open a new issue with the bug or feature template.

## Report a security problem

Do not open a public issue. Follow [SECURITY.md](./SECURITY.md).

## Response times

Sauron is maintained by volunteers, so replies come when time allows.
